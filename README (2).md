# Decoder-only model: Monolingual GPT-2 (text generation)

- Model: https://huggingface.co/TahiraAbbas/gpt2-wikitext
- Base model: `gpt2` (English only)
- Dataset: WikiText-2 (Wikipedia articles)
- Live app: PASTE_YOUR_GPT2_STREAMLIT_LINK_HERE

Files: `app.py` (Streamlit app), `requirements.txt`, `Decoder_GPT2_Colab.ipynb` (fine-tuning code).
